# Зони, часові події та журнал — 02.11.2026

Реалізацію та доступні перевірки завершено. **Перевірка на природному безперервному відео залишається невиконаною**: отримати відповідний матеріал не вдалося. Слайд-відеоряд із val попереднього етапу не використано як перевірку часових подій.

## Реалізовано

- Редактор зон на `/analysis`: створення включення/виключення, drag, resize, клавіатурне редагування координат і назви, зміна правила, видалення, збереження для джерела. Нормалізовані координати враховують фактичне зображення й поля плеєра. Незбережені/незавантажені зони блокують запуск.
- Правило центра рамки, пріоритет виключень, увесь кадр без включаючих зон. Сервер копіює зони джерела в незмінний snapshot нового запуску.
- Окремий часовий модуль: незалежні smoke/fire області, однозначне жадібне зіставлення IoU/центрів, ковзне вікно, різні моменти підтвердження, порожні кадри, кілька областей, об'єднання повторних спостережень до timeout. Короткі кандидати без підтвердження не зберігаються як події.
- Різні first/confirmed/last_seen/closed positions; джерело часу — PTS відео. Completed лише для absence/eof, interrupted для cancelled/failed/worker_interrupted. При аварії без відомого часу зупинки closed/end залишаються NULL, час не вигадується.
- Кадр із рамкою та H.264-фрагмент **із вихідного відео** навколо підтвердження; обмеження тривалістю й фактичними межами кадрів для VFR. Перевірка ffprobe, fsync, атомарна публікація. UUID5 і unique(run_id,track_key) + upsert не створюють дублікати й не скидають оцінки оператора.
- Журнал `/events`: реальні API, пагінація, source/class/period/review filters, картка, JPEG/MP4, усі часи й причина, модель/запуск/snapshot, оцінка й коментар. Optimistic concurrency повертає409 при застарілій картці. Оцінка не змінює автоматичний стан і не запускає навчання.
- `/settings` зберігає часові defaults і типову частоту в технічній app_settings. Форма аналізу дозволяє уточнити параметри для одного запуску; минулі snapshots не змінюються.
- Міграція `0004_zones_events`: observation_zones у video_sources; track_key/last_seen_seconds/closed_seconds/closure_reason та interrupted-стан у наявній events; app_settings для defaults. Source_id у events не дублюється; покадрових SQL-таблиць не додано.

Інженерні defaults: fps2, window3с, min_hits3, min_span1с, absence2с, IoU.1, normalized center distance.12, clip before2с/after3с. Перевіряється узгодженість із частотою; це не оптимізовані значення. Повна специфікація й API: [docs/EVENTS.md](../../docs/EVENTS.md).

## Джерела природного відео та обмеження

Перевірено305 доступних проектних відеофайлів: це попередній val-монтаж/його результат або технічні файли ізольованих тестів. Перелік і межі пошуку: [source-search.json](source-search.json). Середовище/кеші, зображення датасету й архіви навчання повторно не сканували; недоступні каталоги зазначені в JSON, перевірені доступні матеріали не називаються вичерпним аудитом усіх дисків.

Переглянуто [README авторів D-Fire](https://github.com/gaia-solutions-on-demand/DFireDataset), його розділ surveillance videos та посилання на первинні публічні джерела. Спроби:

- [Відео авторів на OneDrive](https://1drv.ms/f/c/c0bd25b6b048b01d/EhT2Jy6L-YlGvZv-gXH2SnYBENQsnUW96LpZtv_6PngjYQ): веб-інструмент не зміг відкрити перенаправлення; звичайний PowerShell-запит завершився WebException. Відео не отримано; це не доказ, що ресурс недоступний усім користувачам.
- [FESB video database із посилання авторів](https://wildfire.fesb.hr/index.php?option=com_content&view=article&id=50&Itemid=55): веб-доступ завершився timeout/inaccessible; звичайний запит теж WebException: [fesb-request.json](fesb-request.json).
- Для додаткових AoF відео README авторів вказує реєстрацію; авторизацію не обходили, облікові дані не вигадували.

Для ручного отримання підготовлено `D:\FireVision\materials\natural-video` (поки порожньо, великі матеріали виключені з Git). Після отримання потрібні URL/дата/права/SHA-256, потім звичайне завантаження через `/sources` і новий аналіз. Старий val-слайд-відеоряд не підміняє цю перевірку.

**Залишається:** реальний YOLO + часовий алгоритм на природному неперервному відео з полум'ям/димом і негативними фрагментами, ручна часова/просторова перевірка доказів. Походження сцен треба перевірити окремо; матеріал не можна автоматично оголошувати незалежним науковим test. Зменшення хибних тривог не доведено. Код/тести не заблоковані; доступний природний відеоматеріал є блокером саме цієї зовнішньої перевірки.
