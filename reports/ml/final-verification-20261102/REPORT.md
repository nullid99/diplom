## Запуск і межі готовності

API/UI зараз запущені, GPU дозволений **лише env-змінною процесів**, `.env`, ML-залежності, дані та навчальну конфігурацію не змінювали. Worker перевірки вже завершився; для нових завдань потрібен окремий worker. З нового PowerShell, після підтвердження відсутності навчання:

```powershell

.\scripts\start-backend.ps1     # якщо API вже працює, другий не запускайте
# Інше вікно:

.\scripts\start-frontend.ps1
# Ще одне вікно:
Set-Location D:\FireVision
$env:ANALYSIS_ALLOW_GPU = 'true'

```
